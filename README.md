# XIII.dog

Personal site for XIII — photographer, maker and party animal, creator of RUFFHOUSE.

Plain HTML/CSS, hosted with GitHub Pages. Edit any `.html` file and push to `main`; the site updates in a minute or two.

- `index.html` – Home
- `socials.html` – Socials + support (Venmo / Cash App)
- `ruffhouse.html` – RUFFHOUSE + RUFF Games
- `where-ill-be.html` – upcoming events + Google Calendar embed
- `photography.html` – filterable photo gallery
- `sewing.html` – Stitching & Sewing
- `images/` – photos · `assets/style.css` – shared styles
